### Android APK

With Unity + Android Build Support installed:

```bash
cd MicroEvolution
# Menu: MicroEvolution → Build Android APK
# or:
UNITY_EDITOR=/path/to/Unity ./Scripts/build-android-apk.sh
```

Output: `MicroEvolution/Builds/Android/MicroEvolution.apk`
